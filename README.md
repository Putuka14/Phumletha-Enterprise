# Phumletha Enterprise Website

A responsive multi-page website for **Phumletha Enterprise** featuring:

- Home
- About
- Services
- Contact Us
- Cash Loans
- Goods Delivery Transport
- "& Beyond" business services
- Responsive mobile navigation
- WhatsApp enquiry form
- Your supplied Phumletha Enterprise logo

## Open in Visual Studio Code

1. Extract the ZIP file.
2. Open Visual Studio Code.
3. Select **File > Open Folder**.
4. Choose the `Phumletha_Enterprise_Website` folder.
5. Open `index.html`.
6. Install the VS Code extension **Live Server**.
7. Right-click `index.html` and choose **Open with Live Server**.

## Before going live

For a production website, add:

- Official company contact details
- Official business address
- Privacy Policy
- Terms & Conditions
- Loan-specific legal/compliance information applicable to South Africa
- Secure server-side handling for any personal information
- A real form backend if you want email submissions
- SSL/HTTPS

The cash-loan wording in this template is intentionally general. Actual loan products, rates, fees, affordability criteria and regulatory disclosures should be reviewed before publishing.
